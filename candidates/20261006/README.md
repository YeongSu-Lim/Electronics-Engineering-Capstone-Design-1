# 2026-10-06 후속 코드 · 격리 검토 후보

[비교·검증 기록](../../docs/followup-20261010.md)

루트의 기존 실행 코드는 그대로 유지됩니다. 이 디렉터리는 제공된 후속 ZIP의 Python 파일을 가져온 검토 후보이며 테스트 파일만 `tests/`로 분리했습니다. 실장치 검증 버전이 아닙니다.

모의 테스트 (저장소 루트):

```sh
cd candidates/20261006
python3 -m unittest discover -s tests -v
```

장치 실행 준비: 이 디렉터리의 `config.py`에서 HEF 및 영상 경로를 실제 파일 위치로 설정하고, HailoRT·Supervision·OpenCV/GStreamer 호환성을 확인해야 합니다. 기본 HEF 경로는 현재 작업 디렉터리 기준이므로 루트 모델을 자동 발견하지 않습니다. 준비 후 이 디렉터리에서 `python3 main.py`를 실행하는 구조입니다. 이 장치 명령은 여기서 실행하지 않았습니다.

CSV·영상·BLE 파일 기록은 기본 활성화되어 있습니다. 기록 경로·디스크 여유 공간을 확인하고, 시험 영상의 얼굴·번호판 및 메타데이터의 로컬 경로를 검토하기 전 공개하지 마세요. BLE는 공유 파일 출력이며 무선 송신기는 포함하지 않습니다.

테스트 디렉터리 분리에 따라 `test_csv.py`·`test_full.py`의 소스 해시 기준 경로를 부모 디렉터리로 수정했습니다. 최초 배치 검사에서 이 경로로 인한 실패 1개를 확인한 뒤 수정·재실행했습니다. Python 3.12.14 사용.
