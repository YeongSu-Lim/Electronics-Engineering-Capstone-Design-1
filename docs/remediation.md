# 코드 수정·검증 계획

[README](../README.md) · [현재 분석](algorithm.md) · [버전 구분](versions.md)

**이번 PR에는 실행 코드·의존성·HEF 변경이 없습니다.** 후속 ZIP의 기능을 적용할 때도 별도 기능 PR로 검토합니다. 아래 통과 기준은 계획이며 실제 장치 시험 결과가 아닙니다.

| 우선순위 | 문제 또는 확인 과제 | 제안 수정 범위 | 검증·통과 기준 |
| --- | --- | --- | --- |
| P0 · 실행 호환성 | HEF 출력의 6개 값 행 구조 가정, 패키지 버전 미고정 | 실제 Hailo 입출력 메타데이터·dtype·클래스 구조 확인 후 파서/환경 확정 | 대상 HEF·HailoRT에서 빈 검출·복수 클래스·경계 박스 처리와 좌표 검증 |
| P0 · 판정 근거 | 무효 TTC 뒤 과거 평균이 남아 위험 횟수 증가 | 현재 raw와 평균 조건, 무효/축소·정체 시 근거 초기화 검토 | 기록된 합성 회귀 사례에서 과거 TTC만으로 DANGER 진행하지 않음; 실제 접근 누락률도 함께 평가 |
| P1 · 이력 관리 | 빈 검출에서 tracker 갱신 생략, 누락/ROI 이탈 이력 잔존 | 빈 검출 갱신·누락 처리·만료·조건 이탈 정책 적용 검토 | 빈 프레임·ID 변경·재진입에 오래된 위험 횟수 재사용 없음, 장시간 ID 저장량 확인 |
| P1 · 시간 기준 | 처리 시각 기반 TTC, 잘못된 시간 차를 임의 치환 | 단조 시간/프레임 시간 기준 통일, 중복·역행 처리 | 같은 영상의 재생 처리 속도 변경에 결과가 불필요하게 달라지지 않음 |
| P1 · 장치 통합 | 최신 MAIN/로그/BLE가 현재 main에 없음 | 후속 기능은 별도 PR, 같은 대상의 상태·TTC·경보·기록 연결 | MAIN 전환·누락·파일 실패 시 일관성, MP4/CSV 프레임 대응 및 실제 무선 수신 확인 |
| P2 · 성능 근거 | 과거 수치의 시험 버전·표본·정답 미확인 | 평가 프로토콜·라벨·설정·결과 기록 구축 | 동일 입력 비교와 시험 단위/분모 명시, FP/FN 및 처리 지연·메모리 기록 |

후속 자료의 모의 테스트 34개 통과는 로직 검증의 일부입니다. 실제 Hailo·카메라·인코더·BLE·야외 성능을 대신하지 않습니다. `SAFE/NONE`은 실제 안전 확인이 아니며, 공유 파일 쓰기 성공은 무선 수신 성공이 아닙니다.
